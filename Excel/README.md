📊 OTT Customer Analysis using Microsoft Excel

📌 Project Overview

This project analyzes OTT customer data using Microsoft Excel. The analysis focuses on customer demographics, OTT platform distribution, subscription types, locations, gender, age groups, and account tenure.

🛠️ Tools & Features

- Microsoft Excel
- Data Cleaning
- Pivot Tables
- Pivot Charts
- KPI Analysis
- Dashboard
- Slicers
- Data Visualization

📊 Analysis Areas

- Customer Distribution by Age Group
- Customer Distribution by OTT Platform
- Platform-wise Average Account Tenure
- Customer Distribution by Location
- Customer Distribution by Gender
- Platform-wise Subscription Distribution
- Customer Analysis by Year

🎛️ Interactive Features

- Age Group Filter
- Subscription Type Filter
- Platform Filter
- Gender Filter
- Year Filter

📈 Dashboard KPIs

- Top OTT Platform
- Total Customers
- Average Account Age
- Top Subscription Plan
