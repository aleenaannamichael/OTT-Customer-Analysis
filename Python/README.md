🐍 OTT Customer Analysis using Python

📌 Project Overview

This project analyzes OTT customer data using Python. The analysis includes data exploration, data cleaning, customer demographics, OTT platform distribution, subscription types, locations, age distribution, gender, and preferred language.

🛠️ Tools & Libraries

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook / Google Colab

🔍 Data Exploration

The notebook performs:

* Dataset preview
* Dataset shape and structure analysis
* Column inspection
* Descriptive statistics
* Data type inspection
* Missing value checks
* Duplicate record checks
* Unique value analysis

🧹 Data Cleaning

The project includes:

* Removing duplicate records
* Converting `SignupDate` to datetime format
* Checking data types after transformation

📊 Analysis Performed

* Customer distribution by OTT platform
* Gender distribution
* Subscription type distribution
* Customer age analysis
* Average account age by OTT platform
* Platform-wise subscription analysis
* Customer distribution by location
* Preferred language distribution

📈 Visualizations

The notebook creates visualizations for:

* Customer Distribution by OTT Platform
* Customer Age Distribution
* Subscription Type Distribution
* Customer Distribution by Location
* Customer Distribution by Preferred Language

📁 Files

* `OTT_Customer_Analysis.ipynb`

> The dataset used for the analysis is available in the `Dataset` folder.
