📊 OTT Customer Analysis using Power BI

📌 Project Overview

This project presents an interactive Power BI dashboard for analyzing OTT customer data.

The dashboard provides insights into customer demographics, OTT platform preferences, subscription types, locations, gender, age groups, and account tenure.

🛠️ Tool Used

* Microsoft Power BI
* Power Query
* Data Visualization
* Interactive Dashboard

📊 Analysis Areas

The dashboard focuses on:

* Total Customer Analysis
* OTT Platform Distribution
* Customer Distribution by Age Group
* Customer Distribution by Gender
* Subscription Type Analysis
* Customer Distribution by Location
* Platform-wise Account Tenure
* Customer Analysis by Signup Year

🎛️ Interactive Analysis

The dashboard allows users to explore customer data using interactive filters and visualizations.

Key filtering dimensions include:

* Age Group
* Subscription Type
* OTT Platform
* Gender
* Year

📈 Dashboard Insights

The dashboard provides a visual overview of:

* Customer base and distribution
* Most-used OTT platforms
* Subscription preferences
* Customer demographics
* Geographic distribution
* Account tenure patterns
* Signup-year trends
