📂 OTT Customer Analysis Dataset

📌 Overview

This folder contains the dataset used for the OTT Customer Analysis project.

The dataset is used across Excel, SQL, Python, and Power BI for data cleaning, analysis, visualization, and dashboard development.

📊 Dataset Information

The dataset contains customer-related information used to analyze:

- Customer demographics
- OTT platform preferences
- Subscription types
- Age groups
- Gender
- Customer location
- Preferred language
- Account tenure
- Signup year

🛠️ Used For

- Microsoft Excel
- MySQL Workbench
- Python
- Power BI

📁 File

- `raw_datatest.csv`

> This dataset is used as the common source for the analysis performed in the other project folders.
