🗄️ OTT Customer Analysis using MySQL

📌 Project Overview

This project analyzes OTT customer data using MySQL. SQL queries are used to examine customer demographics, OTT platform preferences, locations, subscription types, account tenure, and data quality.

🛠️ Tool Used

- MySQL Workbench
- SQL

 🗃️ Database

Database Name:

`ott`

Main Table:

`ott_customers`

The table contains:

- Customer ID
- Platform
- Age
- Age Group
- Gender
- Location
- Account Age (Months)
- Signup Date
- Preferred Language
- Subscription Type

📊 SQL Analysis

The project includes:

- Total Customer Count
- OTT Platform Analysis
- Age Group Analysis
- Location Analysis
- Top 5 Locations
- Gender Analysis
- Subscription Type Analysis
- Average Account Age by Platform

🔍 Data Quality Checks

- Duplicate Customer IDs
- Missing Platform Values
- Invalid Age Values

📈 Advanced SQL

- Aggregate Functions
- GROUP BY
- ORDER BY
- HAVING
- LIMIT
- Window Functions
- RANK()
