📺 OTT Customer Analysis

📌 Project Overview

This project is an end-to-end OTT Customer Analysis project developed using Microsoft Excel, MySQL, Python, and Power BI.

The project analyzes customer demographics, OTT platform preferences, subscription types, locations, preferred languages, account tenure, and customer trends to generate meaningful business insights.


🎯 Project Objectives

- Analyze OTT customer demographics
- Compare customer distribution across platforms
- Analyze subscription preferences
- Understand customer age groups
- Analyze customer distribution by location
- Compare customer gender distribution
- Analyze preferred languages
- Evaluate account tenure across platforms
- Identify key customer trends and insights


🛠️ Tools & Technologies

- **Microsoft Excel** – Data Cleaning, Analysis & Dashboard
- **MySQL Workbench** – SQL Analysis
- **Python** – Exploratory Data Analysis (EDA) & Data Visualization
- **Pandas** – Data Manipulation
- **NumPy** – Numerical Analysis
- **Matplotlib** – Data Visualization
- **Seaborn** – Statistical Visualization
- **Power BI** – Interactive Dashboard & Business Intelligence
